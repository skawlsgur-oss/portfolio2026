## 1. 📌 프로젝트 개요 (Overview)

### 1.1 배경 및 목적
* **배경:** AI 도구(ChatGPT, Claude, Gemini, Cursor 등)를 활용해 직접 제작한 다양한 웹/앱 작업물을 수강생들에게 선보이고, 실제 구현 경험과 노하우를 공유할 수 있는 포트폴리오 공간이 필요합니다.
* **목적:** 
  1. 수강생(성인)에게 **"AI로 이러한 완성도 높은 결과물을 만들 수 있다"**는 비전과 학습 동기를 부여합니다.
  2. 단순 결과물 전시를 넘어 **AI 프롬프트 및 제작 노하우**를 공유하는 교육적 가치를 제공합니다.
  3. 전용 **관리자 페이지(`admin.html`)**를 통해 코드 수정 없이 자기소개와 작업물(CRUD)을 쉽고 빠르게 최신화합니다.

 ├── 1. 상단 바: 대시보드 타이틀 / [포트폴리오 보러가기] / [로그아웃]
 ├── 2. 현황 통계 카드: 총 작업물 수, 카테고리 분포, 데이터 저장 상태

### 4.2 상세 기능 요구사항

#### ① 관리자 인증 & 라우팅 (Admin Auth & Routing)
* **인증 절차:**
  1. 메인(`index.html`) 또는 내비게이션 바의 `🔒 관리자 로그인` 클릭.
  2. 비밀번호 인증 모달에 PIN/비밀번호(`1234`) 입력.
  3. 검증 성공 시 `LocalStorage`에 관리자 로그인 세션(`portfolio_is_admin = true`)이 저장되며 전용 관리자 페이지인 **`admin.html`**로 자동 리다이렉트.
* **세션 관리:**
  * 관리자로 로그인된 상태에서는 브라우저 탭을 닫기 전까지 로그인 상태가 유지됩니다.
  * `admin.html` 상단의 `[로그아웃]` 버튼 클릭 시 세션이 해제되고 `index.html`로 이동합니다.

#### ② 관리자 대시보드 페이지 (`admin.html`)
* **자기소개 관리 (Profile Editor):**
  * 강사 이름, 한 줄 직함/비전, 상세 소개글, 주요 기술 태그 칩을 폼에서 입력 후 `[자기소개 저장]` 클릭 시 즉시 반영.
* **작업물 CRUD 관리 (Projects Manager):**
  * **목록 조회:** 현재 등록된 모든 AI 프로젝트를 아이콘, 카테고리, 제목, 사용 도구 태그와 함께 시각적으로 나열.
  * **신규 등록:** `[+ 새 작업물 추가]` 버튼 클릭 시 입력 모달을 통해 제목, 카테고리, 설명, 라이브 데모 URL, GitHub URL, **AI 프롬프트 원문**, **제작 노하우 팁** 입력.
  * **수정/삭제:** 각 작업물 항목별 `[수정]` 모달 열기 및 `[삭제]` 기능 제공.
  * **데이터 초기화 (Data Reset):** 테스트 후 기본 시드 데이터로 언제든지 복원할 수 있는 `[기초 데이터로 리셋]` 기능 제공.

#### ③ 수강생용 AI 프롬프트 & 팁 공유 모달 (Prompt & Tips Modal)
* **기능 설명:** 메인 페이지(`index.html`)에서 수강생들이 각 작업물의 `[AI 프롬프트 & 팁]` 버튼을 클릭하면 팝업으로 관리자가 등록한 프롬프트 원문과 팁을 확인하고 **원클릭 복사** 가능.

#### ④ 문의 & 연락폼 섹션 (Contact Section with EmailJS)
* **기능 설명:** 방문자가 이름, 이메일 주소, 메시지를 입력하고 `[이메일 보내기]` 버튼을 누르면 **EmailJS API**를 통해 지정된 관리자 이메일(`skawlsgur@gmail.com`)로 즉시 발송.
* **유효성 검사 & 피드백:**
  * 필수 항목 입력 여부 및 이메일 형식을 클라이언트 사이드에서 즉시 체킹.
  * 전송 중 버튼 로딩 스피너 애니메이션 표시.
  * 전송 성공 시 폼 자동 초기화 및 성공 토스트 메세지 출력.
