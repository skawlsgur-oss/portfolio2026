# 🌟 남진혁 강사의 AI 포트폴리오 2026 (portfolio2026)

성인 수강생들을 위해 AI 기반 웹/앱 개발 결과물을 선보이고, 실전 AI 프롬프트와 제작 노하우를 공유하는 개인 포트폴리오 웹사이트 프로젝트입니다.

---

## 🎨 디자인 및 기술 특징

* **미래지향적 테크니컬 다크 모드 (Futuristic Dark Theme)**: 딥 스페이스 네이비 배경, 네온 시안/바이올렛 액센트 및 글래스모피즘(Glassmorphism) 카드 인터페이스.
* **🔒 나만 편집 가능한 관리자 모드**: 비밀번호 인증(`1234`)을 통해 웹 화면에서 즉시 자기소개 및 작업물 추가/수정/삭제.
* **💡 수강생을 위한 AI 프롬프트 원클릭 복사**: 실제 프로젝트 제작에 사용된 AI 프롬프트 및 구현 팁 팝업 제공.
* **🧩 모듈형 컴포넌트 설계**: `Navbar`, `Hero`, `ProjectCard`, `ProjectGrid`, `GuideSection`, `Modals`, `Toast` 모듈 분리.

---

## 📁 프로젝트 구조

```
portfolio2026/
├── 📄 index.html            # [메인] 포트폴리오 웹사이트 메인 페이지
├── 🎨 style.css             # [스타일] 통합 다크 모드 디자인 시스템
├── ⚙️ app.js                # [메인 로직] ES 모듈 통합 메인 컨트롤러
│
├── 📁 docs/                 # 기획 및 디자인 문서
│   ├── prd.md            # 요구사항 정의서
│   └── design.md         # 디자인 가이드
│
├── 📁 components/           # 재사용 가능한 ES 컴포넌트 모듈 (100% 한글 주석)
├── 📁 showcases/            # 컴포넌트 데모 (demo.html) & 자동화 검증 (test.html)
└── 📁 assets/               # UI 시안 및 이미지 리소스
```
